# Ionic Biorhythm Calculator

A small **Ionic + React** learning project that calculates and visualizes **biorhythm cycles** based on a user's birth date.

Biorhythms represent three natural cycles believed to affect human life:

- **Physical cycle** (23 days)
- **Emotional cycle** (28 days)
- **Intellectual cycle** (33 days)

This application allows users to input their birth date and visualize their current cycle values.

---

## Features

- Input birth date
- Calculate physical, emotional and intellectual cycles
- Display cycle values visually
- Mobile-friendly UI using Ionic components

## Run the Project Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
ionic serve
```

Or if using React scripts:

```bash
npm start
```
